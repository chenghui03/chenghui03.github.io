## 现象

在深度学习模型中，即使是对同一个样本重复进行预测，每次预测的结果也各不相同（甚至波动较大）
（或者表现为 相同模型CPU和GPU上的结果不相同）


![[attachments/Pasted image 20250424211819.png|对于同一序列进行二分类预测的结果|400]]
从图上可以预测，这种预测不确定性的波动波动范围从0.25-0.7，波动极大。

## 不确定性的来源

### autotune

tensor输入维度（batch 大小、通道数、特征图尺寸）与硬件（SM 数量、内存带宽、缓存层次）复杂多变，对tensor运算使用单一实现无法在所有场景下达到时间最优。为了在不同硬件与输入形状上获得最佳性能，cuDNN 为同一张量操作定义提供多种底层实现。

cuDNN 提供 `cudnnFindConvolutionForwardAlgorithm`（及类似函数），即 **Autotune**，它在首次调用时对一系列候选算法进行基准测试，测量实际运行时间并选择最快者。
#### 举例：卷积运算

- **Implicit-GEMM（im2col+GEMM）**：将输入张量按滑窗重排为矩阵，再调用高度优化的矩阵乘法（GEMM）。
- **FFT-based**：对输入与核先做快速傅里叶变换，频域点乘再反变换，乘法次数随核大小下降，适合大核。
- **Winograd 最小滤波**：利用 Winograd 算法减少乘加次数，适合小核（如 3×3）

进行基准测试时候可能导致多算法切换，从而引入的数值偏差。

> [!NOTE] 核函数 和 单一内核实现
> 核函数（kernel function）指的是运行在 GPU 上的 CUDA kernel，即由  deep learning 框架 调用、用于执行特定张量操作（如卷积、归约、矩阵乘等）的底层程序。
> 单一内核实现是指对于某一张量操作（如 `tf.nn.conv2d`），只使用 一个固定的 CUDA kernel 实现来执行，而不启用多个候选实现之间的动态选择（即不启用 Autotune），牺牲性能以换取数值稳定性和完全复现性。

### 并行运算

浮点加法在数值计算时并不满足结合律，在并行环境下，不同线程对部分和的合并顺序不固定，就会产生微小的舍入差异。  

`TF_DETERMINISTIC_OPS=1` 强制所有可并行化的浮点运算（如卷积、归约）退回到固定的加法顺序或单一内核实现，从数学上保证相同输入与顺序下，每次运算结果完全一致。

### 浮点数精度

CPU默认精度为float32，GPU在mix精度中会使用float16以节约显存

### 随机种子

随机种子是伪随机数生成器（PRNG）初始化状态的输入值。

| 层或函数                                       | 随机行为         |
| ------------------------------------------ | ------------ |
| `Dense`, `Conv2D`                          | 初始化          |
| `Dropout`                                  | 单元丢弃（预测时应禁用） |
| `GaussianNoise`, `GaussianDropout`         | 噪声生成         |
| `Embedding`                                | 初始化          |
| `tf.keras.initializers`（如 `GlorotUniform`） | 初始化          |

## 如何得到确定性结果

在代码前加入以下行

```python
import os
import tensorflow as tf
import random

# 禁用 Autotune
os.environ['TF_CUDNN_USE_AUTOTUNE'] = '0'
# 使用确定性数值计算
tf.config.experimental.enable_op_determinism()
os.environ['TF_DETERMINISTIC_OPS'] = '1'

# 强制使用统一精度
tf.keras.backend.set_floatx('float32')

# 设置随机种子
random.seed(42)
np.random.seed(42)
tf.random.set_seed(42)
```
